# Description
This is a mod for Crash Team Racing that makes players and CPU-controlled racers jump uncontrollably at all times.

# Building
In order to build this, you must first set up `psx-modding-toolchain` and `CTR-ModSDK` according to the instructions listed for those projects. Once you have a working build enviornment, copy the `AlwaysJumpingMod` folder of this repository into `CTR-ModSDK/mods/Modules/` and then run its `./build.bat`

# Downloading and running the mod
Go to the Releases page of this repository and download `ctr-u_AlwaysJumpingMod.xdelta`, then use any patching tool to apply this to the NTSC-U version of Crash Team Racing. This contains no other modifications to the game and will run in 4:3 instead of widescreen. If you want to have additional features, you will have to build this mod with the relevant settings enabled in the `CTR-ModSDK` repository.

Additional work may be required for this mod to be compatible with the NTSC-J or PAL versions of the game.
